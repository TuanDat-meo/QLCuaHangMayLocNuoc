# Admin Web - React TypeScript

Ứng dụng quản lý cho admin của hệ thống AquaCare

## Cấu trúc thư mục

- **components/** - Tái sử dụng được các React component
- **pages/** - Các trang chính (Dashboard, Orders, Machines, etc.)
- **hooks/** - Custom React hooks
- **store/** - State management (Redux/Zustand, etc.)
- **services/** - API calls và Firebase integration
- **utils/** - Utility functions
- **types/** - TypeScript type definitions
