# Customer App - Flutter

Ứng dụng cho khách hàng của hệ thống AquaCare

## Cấu trúc thư mục

- **features/** - Các tính năng chính (orders, machines, profile, support, etc.)
- **core/** - Services lõi (Firebase, API, Authentication, etc.)
- **shared/** - Components, widgets, constants dùng chung
- **utils/** - Utility functions
