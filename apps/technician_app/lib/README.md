# Technician App - Flutter

Ứng dụng cho kỹ thuật viên của hệ thống AquaCare

## Cấu trúc thư mục

- **features/** - Các tính năng chính (tasks, machines, reports, etc.)
- **core/** - Services lõi (Firebase, API, Authentication, etc.)
- **shared/** - Components, widgets, constants dùng chung
- **utils/** - Utility functions
